## What a row means

- **Claim**: how the platform registry rates the extension (`strong` carries a detection alone; `weak` only narrows). Neither is a verified game identity.
- **Library route**: how a loose file reaches a Library row through Add Source -> Scan. `NOT STORED` means the plain scan never persists it; for a strong claim that is a defect unless the Deferred section explains it.
- **Ingestion**: the category the discovery pipeline assigns from the extension; `-` means discovery reports the extension as unsupported.
- **Extension alone**: the platform detector's verdict for the file in a folder that names no platform, with no bytes read. Every such verdict requires confirmation.
- **Stored as**: the platform the scan actually records for that file (the detector's verdict filtered by the registry's conflict policy); `-` means stored without a platform, waiting for a person.
- **Launch** and **Evidence** describe the *platform*, not the file: the reviewed standalone launch mapping and the engineering evidence coverage.

## Deferred strong claims

Strong claims the Library scanner knowingly does not persist. Each needs a reason; the test suite keeps this list exact.

| Extension | Platform | Reason |
|---|---|---|
| `.gdi` | Dreamcast | a GD-ROM is a sheet plus track files; the explicit Discovery import validates every track as a companion (`ingestion::gdi`), the plain scan has no structural gate yet |
| `.ecm` | PSX | ECM is a generic error-correction-stripped wrapper around any CD image, not a PlayStation format; it needs a wrapper inspector before any platform claim |
| `.wad` | Wii | collides with DOOM-engine IWAD/PWAD files; needs the Wii WAD header check before a loose file is stored as a Wii title |
| `.n-gage` | NGage | non-standard extension with no documented container; no inspector exists |
| `.d81ns` | Commodore 64 | unknown variant of .d81 with no documented layout; registry claim under review |

## Reviewed notes

- `.sap`: also the Atari 8-bit SAP music format; a Thomson-only weak claim stores it with no platform, and `thomson_sap::parse_thomson_sap` could gate it.
- `.3ds`: also the 3D Studio mesh format; a loose file in a neutral folder is offered as Nintendo 3DS on the extension alone and still needs confirmation.
- `.nca`: every content archive of an extracted Switch title becomes its own row; title-level grouping is not implemented.
- `.thd`: a PC-98 hard-disk image, which may hold several games or none; stored as one row.
- `.cia`: with .nsp/.nca/.vpk: discovery counts these as archives (installable packages) while the Library stores them as direct game images, the same precedent as .pkg.
